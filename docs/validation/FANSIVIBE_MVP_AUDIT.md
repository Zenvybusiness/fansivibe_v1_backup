### MVP Boundary Decisions

**MUST EXIST** (10 items): Hairstyle face scan, decision engine, knowledge catalog, analysis run polling, save with Idempotency-Key, `look_saved` learning signal, backend dev auth seam, PostgreSQL with 8 tables, GoRouter navigation, Hairstyle result screen + save button.

**CAN BE MANUAL** (4 items): Face scan image capture (gallery vs. camera), analysis polling (manual check), save action (manual record), catalog look selection (static list).

**POSTPONE** (4 items): Grooming flow, Home screen, Discover screen, Wardrobe screen.

**REMOVE FROM FIRST TEST**: No features — all KEEP-listed features are essential to the core value mechanism, and POSTPONE features are excluded by definition.
