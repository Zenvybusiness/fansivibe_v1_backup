# Fansivibe Studio Synthetic Product Imagery (Task DISCOVERY-10B-1)

## 1. Overview & Provenance

This directory contains deterministic, local studio product imagery assets generated exclusively for Fansivibe development fixtures.

- **Origin**: Original procedural studio graphics generated by `backend/app/static/generate_fixture_assets.py`.
- **Purpose**: Offline-first, routable product imagery for the 60 synthetic development fixture products in `FASHION_SEED_RECORDS`.
- **License**: MIT / Proprietary Fansivibe Project Development Asset.
- **Retailer Image Restrictions**: Zero third-party or restricted retailer images (Flipkart, Amazon, Myntra, Zara, Adidas) are scraped, downloaded, hotlinked, or proxied.
- **Synthetic Disclosure**: All assets are explicitly declared synthetic fixtures (`attributes.fixture = True`, `attributes.synthetic = True`). They must never be presented as genuine commercial retailer stock.

## 2. Asset Specifications

- **Format**: 8-bit RGBA PNG (`image/png`), non-interlaced, encoded via standard library `zlib` + `struct`.
- **Dimensions**: 320 x 390 px (Aspect ratio ~0.82, matching the Digital Atelier 65% hero card visual container).
- **Weight**: ~6.2 KB to 6.4 KB per asset; total footprint < 500 KB across all 61 files.
- **Categories Covered**:
  - Tops (14): `SEED-TOP-001.png` to `SEED-TOP-014.png`
  - Bottoms (12): `SEED-BOT-001.png` to `SEED-BOT-012.png`
  - Outerwear (12): `SEED-OUT-001.png` to `SEED-OUT-012.png`
  - Footwear (12): `SEED-FTW-001.png` to `SEED-FTW-012.png`
  - Accessories (10): `SEED-ACC-001.png` to `SEED-ACC-010.png`
  - Default Fallback: `default_fixture.png`

## 3. Serving Architecture

- **Backend Mount**: Mounted in FastAPI via `app.mount("/static", StaticFiles(directory=str(_static_dir)), name="static")` in `backend/app/main.py`.
- **Dynamic Resolution**: Root-relative URLs (`/static/fixtures/fashion/*.png`) are dynamically expanded by `backend/app/api/routers/discovery.py` into fully-qualified routable URLs matching the client's actual request host (`request.base_url`), or overridden by `FANSIVIBE_STATIC_ASSET_BASE_URL`.
- **Client Resolution**: Flutter client resolves relative and loopback hosts via `AppConfig.resolveImageUrl` in `lib/core/config/app_config.dart`.
