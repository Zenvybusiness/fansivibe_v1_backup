# Fansivibe Project Context

## Product

Fansivibe is an AI-powered personal style, fashion, grooming, and
confidence assistant.

Its purpose is to help users make personalized style decisions.

Fansivibe is not primarily an e-commerce app, social network, or generic
AI chatbot.

## Core Value

Fansivibe helps users answer:

- What should I wear?
- Does this outfit work for me?
- How can I improve this outfit?
- What can I build from my wardrobe?
- Which hairstyle may suit me?
- Which beard or glasses style may work for me?
- What should I wear for an event?
- How is my personal style improving?

Recommendations should be personalized, constructive, explainable,
respectful, and practical.

## Main Product Areas

Primary navigation:

- Home
- Discover
- Stylist
- Wardrobe
- Profile

### Home

Daily personalized style dashboard.

### Discover

Personalized and trending looks with match explanations.

### Stylist

Launcher for specialized AI workflows:

- Outfit Scan
- Build Outfit
- Hairstyle
- Beard / Glasses
- Event Planning

### Wardrobe

Digital clothing collection and AI wardrobe context.

### Profile

The user's evolving Style Identity, including Style DNA, Style Score,
progress, and saved looks.

## Product Direction

Fansivibe should feel:

- premium
- modern
- intelligent
- warm
- personal
- trustworthy

Avoid childish, noisy, generic chatbot, or marketplace-style UI.

## Development Direction

Frontend: Flutter

Backend direction: Python FastAPI

Database direction: PostgreSQL

AI must be accessed through the Fansivibe backend or an approved
abstraction.

The app is built incrementally and must remain easy to extend with future
features such as skincare, accessories, fragrance, or virtual try-on.

Read `CURRENT_STATE.md` for the current development state.
